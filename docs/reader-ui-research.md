# 开源阅读器调研与 UI/UX 改进

调研日期：2026-11-14（北京时间）。本轮改动基于现有 Bottle 模板与浏览器阅读器，借鉴交互和信息组织，自行实现，不引入下列项目的源码或资源。

## 对比与取舍

| 项目与一手来源 | 值得借鉴的体验 | 本项目的采用方式 |
| --- | --- | --- |
| [Readest](https://github.com/readest/readest)、[快捷键文档](https://www.readest.com/docs/advanced) | 书内搜索、排版主题、键盘导航、可发现的快捷键帮助 | 保留既有排版/搜索，增加帮助弹窗、真正全屏及明确的专注入口；改善弹层焦点 |
| [Kavita](https://github.com/Kareadita/Kavita)、[EPUB 阅读器](https://wiki.kavitareader.com/guides/readers/epub/) | 响应式阅读、书单收藏、自定义首页、章节导航 | 首页优先继续阅读，显示真实阅读进度和最近打开时间；手机阅读控件适配 |
| [Komga](https://github.com/gotson/komga)、[阅读器文档](https://komga.org/docs/guides/webreader-epub/) | 桌面与移动书库、收藏与阅读清单、阅读模式 | 清楚区分文库和阅读界面，突出阅读主动作，收起管理操作 |
| [Koodo Reader](https://github.com/koodo-reader/koodo-reader) | 列表/封面视图、丰富排版设置 | 书架网格/列表切换，格式与进度可视化，统一设置控件 |
| [Calibre-Web](https://github.com/janeczku/calibre-web) | 高级搜索、自定义书架、浏览器阅读 | 搜索—查看命中—加书架—继续阅读闭环，折叠筛选与明确空状态 |

许可证：Readest、Koodo Reader 为 AGPL-3.0；Kavita、Calibre-Web 为 GPL-3.0；Komga 为 MIT。此处是交互研究，非整套阅读引擎迁移；后续若引入源码，应重新核查对应版本的许可要求。

## 已落地

- 统一暖纸色背景、墨绿强调色、卡片、表单、按钮、导航当前状态与中文文案。
- 首页从简单搜索表格改为全文搜索和继续阅读卡片，展示格式、真实进度与时间；无历史时给出下一步入口。
- 搜索筛选逐步展开，保留文件夹、部分日期、排序、顺序及分页；增加 `/` 聚焦搜索和提交反馈。
- 结果突出标题、摘要和命中词；主操作为阅读当前文件夹，便于连续切换章节，保留查看命中及书架入口；单独阅读此文件、下载和预览放入“更多”。
- 书架提供**本页**标题筛选、网格/列表切换、进度条；布局偏好按账号与挂载路径隔离，清除私有缓存时同步清除。
- 加入/移出书架用就地状态反馈，失败可重试；历史页把批量清除放入展开区域，保留原确认机制。
- 登录、账号、历史、搜索设置统一视觉；设置使用有标签的分组表单和明确的选项。
- 阅读器提供全屏、专注、`?` 帮助，以及目录/搜索快捷键；增加侧栏和设置的键盘焦点管理。输入框、输入法组合输入不被快捷键打断。
- 手机主要阅读与书架操作目标至少 44px；响应式布局覆盖 320px、390px 与桌面。
- `lang="zh-CN"`、跳过导航、可见焦点、原生可展开菜单、状态播报和减少动画支持。

## 实现边界

- 延用现有多格式渲染、账号、进度同步和搜索索引；不改变数据库结构。
- 书架筛选明确仅针对当前页，不冒充全库搜索；无 JavaScript 时保留阅读链接、移出书架表单及分页。
- 进度仅展示服务端真实值；未同步时显示“暂无同步进度”，不虚构已读状态。
- 目录、主题、排版和书内搜索在本轮之前已存在，本轮改善其呈现与可用性。
- 全屏能力由浏览器决定，不支持时给出专注阅读替代入口。

## 验证

使用临时 Recoll 索引和 SQLite 账号运行集成及 Playwright 验证，不依赖实际用户的文档或登录信息。覆盖搜索 POST/CSRF、挂载路径、筛选保留、分页、结果加入书架、无结果和无 JS 降级；阅读器覆盖 TXT/EPUB/HTML/CHM/PDF、进度恢复及临时查阅保护。

```sh
.tmp/ux-test-venv/bin/python -m pytest -q tests
node --test tests/*.test.mjs
```
